# Модуль парсера новостей для 1С-Битрикс

## 📌 Описание

Модуль предназначен для **парсинга RSS-новостей с сайта https://lenta.ru** и сохранения их в **ORM-таблицу (D7)**.  
Предусмотрена возможность настройки параметров парсинга через административную панель.

В модуле реализовано:
- парсинг RSS-ленты;
- сохранение данных в ORM-сущность Bitrix D7;
- административный список новостей;
- страница запуска парсинга;
- компонент вывода новостей на фронтенде;
- интеграция с **Vue** и **Bx.Ajax** для динамической подгрузки данных.

**Стек:** Bitrix Framework, ORM (D7), Vue, Bx.Ajax.

---

## 📥 Установка

1. Склонировать модуль в директорию: /local/modules/
2. Перейти в админку → **Маркетплейс → Установленные решения**  
   Установить модуль **kv.parser**.

3. Создать страницу и подключить компонент:
```php
<?$APPLICATION->IncludeComponent(
    "kv:parser.news",
    "",
    [
        "SHOW_DATE" => "Y"
    ]
);?>
```

Настройки модуля доступны по адресу:
/bitrix/admin/settings.php?lang=ru&mid=kv.parser

🚀 Использование
1. Запуск парсера
Перейти в административную панель: /bitrix/admin/kv_news_list.php?lang=ru
На странице списка новостей находится кнопка запуска парсера.

2. Просмотр новостей на сайте
После успешного парсинга перейти на страницу, где подключён компонент.
Новости будут загружены через Vue + Bx.Ajax.

Компонент отображает:
заголовок новости с ссылкой на источник,
дату публикации (если включено).

Фронтенд использует Vue.js с вызовом Bitrix Controller через BX.ajax.runAction().

⚙ Настройки модуля
В административной панели доступны параметры:
URL RSS-ленты для парсинга;
Лимит количества новостей для парсинга.
